# API обмена валют

## Общее описание

Приложение реализует API для работы с валютами и аутентификацией. Оно показывает простую архитектуру, где логика разделена на слои: репозитории, сервисы и эндпойнты. В начале каждого файла есть короткое описание модуля, которое помогает понять назначение кода.

Вместо реальной базы данных используется фейковая БД (`app/core/fake_db.py`), что упрощает запуск и проверку. Такое разделение слоёв делает приложение готовым к масштабированию на реальную СУБД, например PostgreSQL, без серьёзных изменений в логике.

## Описание API

API предоставляет:

- `GET /currencies/list` — список поддерживаемых валют и их кодов;
- `GET /currencies/rates` — обменные курсы для заданной базовой валюты;
- `POST /currencies/convert` — конвертация суммы из одной валюты в другую;
- `POST /auth/login` — получение токена для доступа;
- `GET /auth/me` — информация о текущем пользователе.

Для работы с валютами приложение использует внешний API обменных курсов (`app/utils/external_api.py`). Именно он предоставляет данные о кодах валют, курсах и результатах конвертации.

## Архитектура и слои

Приложение разбито на понятные слои:

- `repository` — слой доступа к данным. В модуле `app/api/repository/users.py` реализовано чтение и запись пользователей в фейковую БД.
- `services` — бизнес-логика. В `app/api/services/users.py` обрабатываются проверки и ошибки при создании пользователя и получении данных.
- `endpoints` — HTTP-слой. В `app/api/endpoints/v1/` находятся роуты для работы с пользователями и валютами.

Такой подход позволяет изолировать HTTP-логику от бизнес-правил и от работы с данными, что делает код чище и проще для адаптации.

## Внешние зависимости

- внешнее API обменных курсов используется для получения актуальных данных о валютах;
- фейковая БД упрощает тестирование и запуск, но при необходимости она легко заменяется на реальную базу.
